# RallyMaster App Future Work

This list tracks RallyMaster capabilities intentionally deferred from the
current route-planning workflow.

## Track mode

- [ ] Add a RallyMaster-only **Track mode** for monitoring a live rally.
- [ ] Show a map with the latest reported location of every registered
  competitor team on the selected rally route.
- [ ] Clearly identify each competitor by car number and provide a useful
  freshness indicator for the last received location.
- [ ] Allow the official to select a competitor from the map or a companion
  list and open an individual competitor view.
- [ ] In the individual competitor view, show the competitor's current or last
  known location, completed checkpoints, per-checkpoint score, and running
  total score.
- [ ] Define the supporting server APIs and data model for periodic primary
  device location reports, checkpoint-completion results, and score summaries.
- [ ] Restrict live tracking data to authorized RallyMaster users in the
  rally's organization and retain it only according to the event privacy and
  audit policy.
